# Baby Diary website

Landing page, privacy policy and support page for the Baby Diary (Nhật Ký Bé Yêu) iOS app, served with GitHub Pages from the `main` branch root.

- `index.html` — landing page and support / FAQ
- `privacy.html` — privacy policy (English); `privacy-vi.html` — Vietnamese
- `assets/` — stylesheet, app icon, app screenshots

Plain static HTML and CSS: no build step, no external fonts or scripts.
